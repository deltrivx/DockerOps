    使用说明

    日常运维

    容器启停、日志、镜像/网络/卷、系统清理与更新检测均可在本控制台完成，无需再开 Portainer 做日常操作。

    管理源分流

    Unraid 走 dockerMan 模板重建，保持 dockerman；Compose 走项目 up/pull；三方 默认仅拉镜像。

    接管开关

    启停/重启/日志：登录即可。删除、prune、模板重建、Compose up/down 需 DOCKEROPS_TAKEOVER_ENABLED=true 且 sock 可写。

    飞牛 / Unraid

    飞牛为引擎级 Compose 接管；Unraid 推荐用模板安装 DockerOps 自身。镜像仅通过 GitHub Actions 远程构建发布到 GHCR。

    登录 DockerOps

    请使用已保存在 SQLite 的账号登录后使用运维控制台。

    忘记密码？

    Web 不提供自助重置。请在 NAS 主机终端执行：

    docker exec -it DockerOps python -m tools.reset_password --username YourUser --password "新密码至少6位"
