使用说明

日常运维

容器启停、日志、镜像/网络/卷、系统清理均可在本控制台完成。镜像更新检测已并入「容器」页（徽标 + 立即检测 / 一键更新）。

管理源分流

Unraid 走 dockerMan 模板重建，保持 dockerman；Compose 走项目 up/pull；三方 默认仅拉镜像。

接管开关

启停/重启/日志：登录即可。删除、prune、模板重建、Compose up/down 需 DOCKEROPS_TAKEOVER_ENABLED=true 且 sock 可写。

飞牛 / Unraid

飞牛为引擎级 Compose 接管；Unraid 推荐用模板安装 DockerOps 自身。镜像仅通过 GitHub Actions 远程构建发布到 GHCR。

远程模式（v0.8）

被控选择协同/托管并填写本机公网域名或 IP，生成 60 秒连接凭证； 主控粘贴凭证即可连接（本机功能不受影响）。不开放 Docker 2375/2376。 托管时被控全屏由远程管理，可点「切换模式」回来。

远程 Docker Engine 端点（可选）

若你已有受控的 Docker API 反代，仍可在「Docker 端点」添加 tcp://docker.example.com:443 + TLS。切勿对公网裸开 :2375。

Docker 端点

默认本机 unix:///var/run/docker.sock。可添加远程 tcp://host:2375（明文）或 tcp://host:2376 + TLS。 域名场景推荐：反向代理暴露 Docker API 后使用 tcp://docker.example.com:443 + TLS（详见「说明日志」）。 活动端点决定容器/镜像等资源视图；Compose 与 Unraid 模板仅本地 unix 端点可用。

Host 示例： tcp://192.168.31.5:2376 · tcp://docker.example.com:443 · ssh://user@host（需本机 ssh 可用）
